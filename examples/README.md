# 配套可运行示例 (examples)

给《[从金融零基础到量化研究者](..)》的读者准备的四个教学脚本。
**零依赖**:只用 Python 3 标准库,不需要 pip install 任何东西,不需要联网。

```bash
cd examples
python3 run_all.py          # 一键跑完四个示例(含各自断言自检)
python3 ex01_factors.py     # 或单独跑某一个
```

## 四个示例对应书里哪里

| 脚本 | 对应主题 | 演示什么 |
|---|---|---|
| `ex01_factors.py` | 从问题到因子、数据与样本切分 | 价值/动量/低波/质量四个教学因子,z-score 合成,五组分层回测,单因子 IC |
| `ex02_index_enhance.py` | 指数增强策略、实战项目一 | 完整指数增强回测:T 日收盘出信号、T+1 生效、月频调仓、万 13 成本、超额/跟踪误差/IR |
| `ex03_lookahead.py` | 回测、识别回测幻觉 | 同一策略偷看未来 vs 不偷看:两条净值曲线的差距就是未来函数白送的部分 |
| `ex04_neutral.py` | 市场中性策略、市场中性模拟盘 | 市场中性账本:Beta 对冲公式、净暴露、保证金占用、对冲前后的波动对比 |

## 设计上的三个刻意选择

1. **用合成数据,不用真实行情**。数据由 `common.py` 里公开的随机过程生成,规律是确定的,
   所以你能精确验证代码有没有发现它该发现的东西。换成真实数据(akshare/tushare/baostock)
   时,只需重写 `load_universe()` 一个函数,其余骨架不变。
2. **时间纪律写死在代码里**。所有因子计算都只看 t 日收盘前的数据,调仓结果从
   t+1 才开始计入收益——书里反复强调的"无未来函数"在这里不是口号,是代码结构。
3. **指标口径与书一致**。年化按 252 个交易日,夏普用 3% 无风险利率,成本双边万 13。

## 上手建议

- 先读 `common.py`,看懂合成数据是怎么生成的——它是判断一切输出是否合理的前提。
- 改参数玩一玩:把 `ex03_lookahead.py` 的 `honest` 翻成 `False` 又改回来;在
  `ex02_index_enhance.py` 里把成本从万 13 调到万 50,看超额还剩多少——这是书里
  "成本敏感性"那张表的可运行版。
- 用这套骨架去接真实数据时,最先要小心的三样东西书里都写了:成分股的历史名单
  (幸存者偏差)、财务数据的公告日(点时可见性)、复权口径。
